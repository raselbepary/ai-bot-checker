          Where to find the log, and supported formats
          
cPanel: Metrics → Raw Access (download the .gz file for the domain). Plesk: Websites & Domains → Logs. Your own server: Nginx or Apache access logs, usually in /var/log/nginx/ or /var/log/apache2/. Cloudflare: Logpush exports (JSON lines). Apache/Nginx “combined” format and JSON lines are supported, plain or .gz, up to 150 MB. The log is analyzed in memory and not stored on the server.
