            Crawler visits
            
        
            Upload a server access log to see which AI crawlers really visited, which pages they read and what they got back. Fake bots are filtered out by checking each visitor's IP address against the lists AI companies publish.
            
      
            
      
            
        
            
          
          
        
            
        
            
        
            
        
            
          Where to find the log, and supported formats
          
            cPanel: Metrics → Raw Access (download the .gz file for the domain). Plesk: Websites & Domains → Logs. Your own server: Nginx or Apache access logs, usually in /var/log/nginx/ or /var/log/apache2/. Cloudflare: Logpush exports (JSON lines). Apache/Nginx “combined” format and JSON lines are supported, plain or .gz, up to 150 MB. The log is analyzed in memory and not stored on the server.

              llms.txt
              
        
              Check a site's llms.txt file and draft one from its pages. llms.txt is an optional, emerging format: a short Markdown guide to your site for AI tools. AI companies haven't widely confirmed using it, so treat it as a low-cost extra rather than a ranking factor.
